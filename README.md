# 시간표 공방

중학교 시간표를 위한 설치 없는 제약 기반 편성 웹앱입니다. 제공된 2026학년도 2학기 시간표가 샘플 프로젝트로 들어 있습니다.

## 실행

가장 간단한 방법은 `index.html`을 더블클릭하는 것입니다. 브라우저 보안 설정 때문에 파일 실행이 제한되면 `start-app.cmd`를 더블클릭하세요. Node.js가 설치된 컴퓨터에서 `http://127.0.0.1:4173` 주소로 앱이 열립니다.

앱은 인터넷이나 외부 서버에 자료를 보내지 않습니다. 수정 내용은 현재 브라우저의 로컬 저장소에 자동 저장됩니다. 중요한 작업은 **데이터 관리 → 프로젝트 백업**에서 JSON 파일로 별도 보관하세요.

## 기본 작업 순서

1. **교사 조건**에서 교사·강사의 근무 가능 요일과 교시별 가능/선호/기피/불가 상태를 입력합니다. 여러 명은 `조건 CSV 내려받기` 후 내용을 수정하여 `조건 CSV 업로드`로 한 번에 반영할 수 있습니다.
2. 강사는 희망 출근일 수와 `공강 없이 연속 배정 선호`를 설정합니다.
3. **수업 시수**에서 학급·과목·담당 교사·주당 시수·연강 단위·특별실을 확인합니다.
4. **자동 편성**을 실행합니다. 기본값은 현재 시간표를 최대한 유지하면서 조건을 위반한 수업만 연쇄 이동하는 최소변경 편성입니다.
5. **시간표 편집**에서 수업을 선택한 후 다른 칸을 눌러 이동 또는 맞교환하고, 유지할 수업은 고정합니다. 이동이 실패하면 실제 조건값과 한도가 오른쪽에 표시됩니다.
6. **충돌 검사**에서 필수 오류를 0건으로 만든 뒤 **데이터 관리 → 전체 시간표 엑셀**에서 결과를 한 번에 내보냅니다.

## 출장·임시 수업교체

사이드바의 **수업 교체**에서 사유, 대상 교사, 요일, 교시 범위를 선택하면 기존 시간표를 수정하지 않고 다음 대안을 계산합니다.

- 출장·연가·연수·병가 교사의 영향 수업 목록
- 전체 교사 시간표에서 다른 교사가 결강 수업을 맡고 결강 교사가 그 교사의 다른 수업을 대신하는 수업교체 후보
- 한 교시, 하루 전체 또는 `3교시 이후 전체`처럼 선택한 범위를 처리할 수 있는 수업교체 조합 최대 12개
- 선택한 임시 교체안을 엑셀 호환 CSV로 저장

수업교체 후보는 양쪽 교사의 수업 중복, 수업 불가 교시, 근무 가능 요일, 일일 최대수업과 최대 연속수업을 가상 시간표에서 다시 검사합니다. 같은 학급 안에서 교시만 옮기는 학급교환과 대강은 제시하지 않습니다. 결과는 임시 계획이므로 정규 시간표와 브라우저에 저장된 원본 배정은 바뀌지 않습니다.

## 교사 일괄 관리

- `교사 조건 → 조건 CSV 내려받기`: 현재 교사별 조건을 엑셀 호환 CSV로 저장합니다.
- `교사 조건 → 조건 CSV 업로드`: 수정한 CSV 파일을 직접 선택하여 근무 가능 요일, 불가·선호·기피 교시, 일일·연속 최대, 희망 출근일, 연강 선호와 메모를 일괄 적용합니다.
- `교사 조건 → 내용 붙여넣기`: 파일을 저장하지 않고 CSV 내용을 바로 붙여넣어 적용할 수도 있습니다.
- 교시 표기는 `월1/화3-4` 형식이며, 빈 칸은 기존 값을 유지하고 `-`는 해당 종류의 교시 조건을 모두 지웁니다.
- `+ 교사 추가`로 교사를 등록합니다. 연결된 수업이 있는 교사를 제거하면 대체 담당자를 선택하여 수업 시수와 현재 배정을 함께 인계합니다.

## 이동 실패 조건표

시간표에서 이동·맞교환이 불가능하면 선택한 수업을 그대로 유지하고 오른쪽 상세 영역에 실패 이유를 표시합니다. 선택 수업과 대상 수업의 고정 여부, 양쪽 교사의 근무 요일과 교시 상태, 같은 시간의 교사 중복, 이동 후 일일 수업 수와 최대값, 연속수업 수와 최대값, 특별실 중복을 `충족/주의/불충족`으로 구분합니다.

## 처리하는 조건

- 교사별 근무 가능 요일과 수업 불가 교시
- 선호·기피 교시
- 강사의 희망 출근일 수와 연속 배정
- 교사별 일일 최대 수업과 최대 연속수업
- 학급·교사·특별실의 같은 교시 중복
- 학급별 과목 주당 시수
- 2시간 연강 묶음
- 고정수업과 창체 등 특별수업
- 출장·결강 시 전체 교사 시간표를 이용한 교사 간 수업교체 후보 탐색
- 같은 날 같은 과목 반복, 강사 공강, 출근일 분산에 대한 권고

필수 조건은 자동 편성이 반드시 피해야 하는 규칙이고, 선호 조건은 가능한 범위에서 점수를 개선하는 규칙입니다. 조건이 서로 모순되면 일부 수업이 미배정으로 남으며 충돌 검사에 원인이 표시됩니다.

## 가져오기와 내보내기

- 전체 시간표 엑셀: 첨부한 결과 양식을 기준으로 `교사별 시간표`, `전체교사 시간표`, `학반별 시간표`, `전체학반시간표` 4개 시트를 하나의 `.xlsx` 파일로 저장합니다. `교과교실 배정` 시트는 만들지 않습니다.
- JSON: 앱의 모든 데이터와 조건을 백업·복원합니다.
- 정규화 CSV: `학급, 학년, 담임, 요일, 교시, 과목, 담당교사, 특별실, 구분` 열을 읽습니다. 제공된 분석 CSV도 불러올 수 있습니다.
- 학급별 CSV / 교사별 CSV / 충돌검사 CSV: UTF-8 BOM을 포함하여 엑셀에서 한글이 깨지지 않게 저장합니다.

원본 `.xlsx` 파일 자체를 브라우저에서 바로 읽는 기능은 이 MVP에 포함되지 않았습니다. 현재 학교의 네 파일은 이미 샘플로 변환해 포함했으며, 다른 학기 자료는 정규화 CSV 또는 프로젝트 JSON으로 가져오면 됩니다.

## 포함된 학교 샘플

- 30학급, 56교사·강사
- 정규수업 930시간, 창체 30시간
- 수업 시수 항목 480개
- 미술 연속수업 20시간을 연강으로 변환
- 강사·운동 담당자의 현재 배정 요일을 근무 가능 요일로 추정
- 원본 파일 사이 담당교사 표기가 다른 9개 지점은 앱의 원본 메모에 표시

샘플의 추정 조건은 실제 계약·업무 조건과 대조한 뒤 수정해야 합니다.

## 기술 메모

앱은 외부 패키지나 네트워크 없이 HTML/CSS/JavaScript만으로 실행됩니다. 자동 편성은 현재 배정 재사용, 제약 우선 탐색, 연쇄 이동, 다중 시도 휴리스틱을 사용합니다. 수학적으로 해의 존재나 전역 최적을 보장하는 상용 최적화 솔버는 아니므로 최종 배포 전 **충돌 검사** 결과와 사람의 검토가 필요합니다.

개발 검증은 `node tests.mjs`로 실행할 수 있습니다.
